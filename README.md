# সৃজনশীল তরুণ সংঘ — GitHub Pages

Repository: `srijonshil2011`

এই প্যাকেজে সংগঠনের ওয়েবসাইটের আপডেটেড কাঠামো রয়েছে।

## প্রধান আপডেট
- নতুন মোবাইল-ফ্রেন্ডলি ডিজাইন ও ক্লিক-ভিত্তিক সাবমেনু
- হোম পেজে সংগঠনের আসল লোগো ও দেওয়া কার্যক্রমের ছবি
- হোম পেজে সব নতুন বিভাগের সংক্ষিপ্ত বর্ণনা
- আমাদের অর্জন, পাঠাগার, প্রতিবেদন, প্রকাশনা, সহযোগিতা করুন, স্বচ্ছতা ও জবাবদিহি, সাধারণ জিজ্ঞাসা এবং সদস্য/স্বেচ্ছাসেবী গল্প
- ইভেন্টের ৩টি সাবমেনু: আপকামিং, আয়োজিত, বাতিলকৃত; প্রতিটিতে ৫টি নমুনা তালিকা
- সদস্য আবেদন ফরমের বর্তমান ব্যবস্থা বজায় রাখা হয়েছে
- যোগাযোগের ইমেইল ও Facebook লিংক বজায় রাখা হয়েছে
